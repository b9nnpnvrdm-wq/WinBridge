WinBridge for Mac

A graphical setup tool for Windows Steam using your own macOS Wine engine.

Download WinBridge for Apple Silicon ↓ SHA-256 checksum

Preview build. Ad hoc signed. Developer ID signing and Apple notarization are pending, so macOS may block the download from opening.

Get started

  1. Unzip the download

    Move WinBridge.app to Applications and double-click it.

  2. Choose your Wine engine

    Select the installed Wine executable in WinBridge.

  3. Set up Windows Steam

    Follow the instructions in the app to install Steam and request a game launch.
